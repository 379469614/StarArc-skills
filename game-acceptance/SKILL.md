# 游戏验收流程控制

>目的是防止AI进行体验型验收，这部分内容十分消耗token且AI完成效率极差

1. 代码编写、场景节点修改或配置更新完成后，允许继续执行静态检查、启动检查、日志检查等可自动确定结果的技术验证；禁止进行需要连续操作、动态视觉判断、游戏手感或复杂交互才能得出结论的动态交互体验验收
2. 需要人类进行动态交互体验验收时直接向人类开发者输出：“开发任务已完成，请在Godot引擎中进行人工验收”，挂起当前任务，等待人类输入引擎内的实际运行结果日志或视觉反馈
