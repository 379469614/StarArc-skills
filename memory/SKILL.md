# 记忆维护

## 目录与远端

- 记忆目录：`~/.codex/memories`
- 远端地址：`git@github.com:379469614/Codex-personal-memery.git`
- 等价地址：`https://github.com/379469614/Codex-personal-memery.git`
- 远端名：`origin`
- 分支：`main`

1. 使用当前系统的用户主目录解析记忆目录
2. 核对 Git 根目录等于记忆目录
3. 缺少远端时配置远端地址
4. 远端指向其他仓库时停止并报告

## 维护前同步

1. 检查工作区，保留未提交内容
2. 获取远端状态，比较提交关系
3. 检查远端其他分支，确认远端是否为空
4. 核对文件清单，检查记忆是否完整
5. 拉取前检查远端新增内容中的敏感信息

按以下状态处理

- 本地为空、远端非空：克隆时不检出文件
- 克隆内容通过检查：检出目标分支
- 本地有文件但无仓库：检查重叠文件后确定接入方案
- 远端为空：检查本地文件和历史，准备首次推送
- 本地落后且工作区干净：检查通过后快进拉取
- 本地领先：检查未推送提交后继续维护
- 历史分叉或无关：停止并报告
- 工作区阻止拉取：停止并报告

## 写入前检查

1. 只保存结论、方法和必要背景
2. 按需从配置来源读取连接信息
3. 写入前剔除敏感信息
4. 检查正文、示例、摘要、补充说明和辅助文件
5. 在允许范围内清除已有敏感信息
6. 无法清除或无法判断时停止提交和推送

剔除以下信息

- 密码、私钥、令牌、API 密钥和恢复码
- 认证头、Cookie、含凭据的 URL 和连接字符串
- 私有服务器地址、SSH 用户名和远程服务路径
- 私人联系方式、身份信息和非公开业务信息

1. 结合上下文区分公开信息与敏感信息
2. 优先省略敏感细节
3. 省略影响理解时才使用占位符
4. 报告只列类别和位置
5. 不输出敏感原值或替换映射

## 提交前检查

1. 检查本轮新增、修改和删除
2. 只暂存获准且相关的记忆文件
3. 排除凭据文件、缓存和日志
4. 排除指向范围外的符号链接
5. 检查实际暂存内容中的敏感信息
6. 清理后重新检查暂存内容
7. 核对提交内容与检查内容一致
8. 检查提交身份和提交说明中的隐私
9. 有变化时自动提交
10. 无变化时不创建空提交

使用记忆仓库已有的 Git 提交身份，未配置提交身份时，停止并询问用户

## 推送前检查

1. 首次推送时检查全部待上传历史
2. 后续推送时检查所有未推送提交
3. 检查历史中的各个文件版本
4. 历史包含敏感信息时停止推送
5. 另行确定历史清理方案
6. 再次获取远端状态
7. 远端变化时重新同步并检查
8. 并发修改时重新确认检查范围
9. 禁止强制推送、硬重置和合并无关历史

## 推送与验证

1. 将检查通过的目标提交推送到 `origin/main`
2. 本轮无变化时仍处理已检查的未推送提交
3. 重新读取远端提交值
4. 核对远端提交与目标提交一致
5. 检查工作区和剩余未推送内容
6. 推送失败时保留本地提交并报告
7. 远端核对通过后报告同步成功
8. 已上传有效凭据时提醒用户撤销或轮换

## 完成报告

1. 说明维护范围和敏感信息处理结果
2. 列出提交值和远端核对结果
3. 说明未完成项
4. 说明规则检查无法保证发现全部敏感信息
