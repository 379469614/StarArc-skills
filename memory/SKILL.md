# 记忆维护与脱敏备份

## 目录与远端

- 记忆源目录：`~/.codex/memories`
- 本地备份仓库：`/home/ubuntu/Projects/CodeXProjects/Codex-personal-memery`
- 远端地址：`git@github.com:379469614/Codex-personal-memery.git`
- 等价地址：`https://github.com/379469614/Codex-personal-memery.git`
- 远端名：`origin`
- 分支：`main`

1. 按当前授权维护记忆源目录
2. 维护完成后生成脱敏备份
3. Git 操作只在本地备份仓库执行
4. 核对 Git 根目录等于本地备份仓库
5. 缺少远端时配置上述远端地址
6. 远端指向其他仓库时停止并报告
7. 远端内容不得回写记忆源目录

## 空记忆检查

1. 同步前检查记忆源目录是否存在
2. 排除 `.git` 等仓库管理数据
3. 空目录和空文件不算有效记忆
4. 仅含空白的文本不算有效记忆
5. 不存在有效记忆时，停止备份和推送
6. 提示用户：“本地记忆为空，请手动添加记忆”
7. 保留已有备份，不因空源删除备份

## 备份仓库同步

1. 检查工作区，保留已有未提交内容
2. 获取远端状态，比较提交关系
3. 拉取前检查远端新增内容中的敏感信息
4. 工作区干净且本地落后时，快进拉取
5. 本地领先时，检查所有未推送提交
6. 历史分叉或无关时，停止并报告
7. 工作区阻止同步时，停止并报告
8. 仓库缺失或文件冲突时，报告接入方案
9. 远端为空时，检查全部待上传历史

## 脱敏副本

1. 以维护后的记忆源目录为唯一内容来源
2. 按原相对路径生成备份副本
3. 脱敏只作用于副本，不回写记忆源目录
4. 只移除敏感信息，不摘要或改写其他内容
5. 保留其他内容、格式、编码和换行
6. 排除 `.git` 等仓库管理数据
7. 不因文件属于日志或辅助文件而跳过
8. 检查正文、示例、摘要和辅助文件
9. 文件名和相对路径也须检查敏感信息
10. 敏感路径或无法安全处理的文件须报告
11. 无法判断或安全脱敏时，停止提交和推送
12. 不跟随指向源目录外的符号链接
13. 遇到此类符号链接时，停止并报告

剔除以下信息：

- 密码、私钥、令牌、API 密钥和恢复码
- 认证头、Cookie 和含凭据的连接信息
- 私有服务器地址、SSH 用户名和服务路径
- 私人联系方式、身份信息和非公开业务信息

1. 结合上下文区分公开信息与敏感信息
2. 优先删除敏感原值
3. 删除影响理解时，使用明确占位符
4. 报告只列类别和位置
5. 不输出敏感原值或替换映射

## 一致性检查

1. 为本轮源文件记录相对路径和内容校验值
2. 以同一批源文件生成脱敏预期副本
3. 按相对路径核对源文件与备份文件清单
4. 未脱敏文件必须逐字节一致
5. 脱敏文件必须与脱敏预期副本逐字节一致
6. 逐项确认源文件差异仅涉及敏感信息
7. 同时核对新增、修改和删除
8. 源文件删除时，同步删除对应备份文件
9. 保留备份仓库自身的 Git 管理文件
10. 无法确认归属的额外文件，停止并报告
11. 提交前重新核对源文件清单和校验值
12. 源文件发生变化时，重新生成并检查副本
13. 发现其他差异时，停止提交并报告
14. 不将含敏感信息的预期副本加入 Git

## 提交前检查

1. 检查本轮新增、修改和删除
2. 只暂存本轮检查通过的备份变化
3. 不夹带仓库原有的无关修改
4. 再次检查实际暂存内容中的敏感信息
5. 核对暂存内容与检查通过的副本一致
6. 检查提交身份和提交说明中的隐私
7. 使用备份仓库已有的 Git 提交身份
8. 未配置提交身份时，停止并询问用户
9. 有变化时自动提交
10. 无变化时不创建空提交

## 推送前检查

1. 首次推送时检查全部待上传历史
2. 后续推送时检查所有未推送提交
3. 检查历史中的各个文件版本
4. 历史包含敏感信息时，停止推送
5. 另行确定历史清理方案
6. 再次获取远端状态
7. 远端变化时，重新同步并检查
8. 并发修改时，重新确认检查范围
9. 禁止强制推送、硬重置和合并无关历史

## 推送与验证

1. 将检查通过的目标提交推送到 `origin/main`
2. 无新增变化时，仍处理已检查的未推送提交
3. 重新读取远端提交值
4. 核对远端提交与目标提交一致
5. 检查工作区和剩余未推送内容
6. 推送失败时，保留本地提交并报告
7. 远端核对通过后，报告同步成功
8. 已上传有效凭据时，提醒撤销或轮换

## 完成报告

1. 说明记忆维护范围和备份范围
2. 说明脱敏结果和一致性检查结果
3. 列出提交值和远端核对结果
4. 说明未完成项
5. 说明敏感信息检查存在漏检可能
