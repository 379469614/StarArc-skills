# 等级显示规范
1. 等级标签必须由程序按固定格式 `Lv. X` 生成
2. 程序写死 `Lv.` 前缀及其后的一个半角空格
3. `X` 替换为实际等级数值，不作为字面文本显示
4. 所有语言均使用该格式，不随语言切换
5. 前缀和完整格式均不得进入本地化流程
6. 不创建翻译键，不写入翻译表，不调用翻译接口
7. 优先复用现有格式化入口，并将其统一为固定格式
8. 没有格式化入口时，按项目结构集中维护固定格式
9. 新增、修改或审查等级标签时，直接统一为本规范
10. 发现其他格式或翻译调用时，直接改为程序固定生成
11. 本规范覆盖项目原有的等级标签格式和本地化约定
12. 本规范仅约束等级标签，说明文字中的“等级”仍可本地化
