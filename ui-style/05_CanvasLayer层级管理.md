# CanvasLayer层级管理
>对应Godot引擎内的CanvasLayer节点的Layer，每个项目单独管理好其Layer，确保界面层级的展现

## 层级划分
| CanvasLayer | 模块 | 包含界面与节点组件 |
| :---: | :--- | :--- |
|0|世界层|专门用于绘制2D游戏世界|
|1～999|主菜单层| 主菜单<br>加载过渡视图（加载遮罩、提示文本、悬浮吐司）<br>过场与广告（广告播放遮罩、过场遮挡带）<br>功能弹窗（设置、胜利/失败/天赋/弹珠/奖励弹窗<br>常驻状态栏（资源顶部条）|
|1000 ~ 1999|主游戏层| `100`：主游戏界面<br>`101`：主游戏暂停弹窗|
|2000+|弹窗通知层| 规划中（全局弹窗、断网提示等）|
|9999|调试工具| `9999`：GM相关控制台，专用层|
