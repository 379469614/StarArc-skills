# 02_组件规范

> 记录 UI 组件在拆分、复用、状态、依赖与职责边界上的强制约束

## 一、组件拆分
1. 同一 UI 结构重复使用 `2` 次及以上时，应优先拆分为独立组件
2. 具有独立交互、独立状态或独立复用价值的结构，应拆分为独立组件
3. 仅使用一次且结构简单的静态 UI，不得为了形式统一强制拆分
4. 单个组件不得同时承担多个无直接关联的功能
5. 组件规模过大时，应按功能边界继续拆分，不按节点数量机械拆分
6. 不允许将整个页面直接封装成“通用组件”以规避页面结构设计

## 二、组件职责
1. 组件只负责自身范围内的显示与交互
2. 组件不得直接控制所属页面之外的其他 UI
3. 通用组件不得包含具体玩法、关卡或业务流程判断
4. 组件不得承担全局状态管理职责
5. 组件不得直接决定页面跳转、场景切换等高层流程
6. 页面级业务逻辑应由页面或上层逻辑负责，组件仅暴露交互结果

## 三、组件输入
1. 组件所需内容必须通过明确输入传入
2. 不允许依赖父节点名称、固定层级或固定场景路径获取数据
3. 不允许通过遍历场景树寻找外部依赖节点
4. 可配置内容应通过统一接口或导出参数提供
5. 不允许在组件内部硬编码仅适用于某个页面的数据
6. 缺少必要输入时，组件不得静默使用无法确认的默认业务值

## 四、组件输出
1. 组件对外行为优先通过信号或明确接口暴露
2. 组件不得直接修改外部兄弟节点状态
3. 组件不得直接调用外部页面内部实现函数
4. 点击、选择、拖拽完成等结果应作为事件对外通知
5. 组件内部视觉状态变化不得被外部通过子节点路径直接控制
6. 外部不得依赖组件内部具体节点结构完成业务逻辑

## 五、内部结构
1. 组件内部节点只服务当前组件
2. 不允许保留无用途或已废弃节点
3. 不允许通过多层空 `Control` 节点组织组件结构
4. 无明确需求时，不得在组件内部创建 `CanvasLayer`
5. 组件内部布局应使用 Anchor、Container 或明确尺寸规则
6. 组件根节点应能明确表达该组件整体尺寸与布局边界

## 六、状态管理
1. 存在多种状态的组件必须明确状态集合
2. 同一状态不得由多个互相独立的布尔变量组合表达
3. 状态切换必须统一更新对应视觉与交互状态
4. 禁用状态必须同时禁止对应输入
5. 不允许出现视觉显示为禁用但实际仍可交互的情况
6. 组件初始化时必须进入明确状态，不依赖旧状态残留

## 七、按钮类组件
1. 同类按钮的结构与交互逻辑应复用同一基础组件
2. 仅颜色、文字或图标不同的按钮，不得复制多套独立结构
3. 高亮、普通、警示等按钮差异优先通过样式或配置表达
4. 按钮内部图标与文字不得分别承担独立点击区域，除非功能明确不同
5. 按钮有效点击区域必须满足交互规范中的最小尺寸要求
6. 禁止为每个业务按钮单独编写一套基础点击逻辑

## 八、列表项组件
1. 重复列表内容必须使用统一列表项组件
2. 列表项不得依赖自身位于第几个子节点判断业务身份
3. 列表项必须通过传入数据确定显示内容
4. 列表项内部不得直接修改列表中其他项目
5. 单个列表项状态变化应通知列表或上层逻辑处理
6. 列表项不得通过兄弟节点路径实现互斥选择

## 九、弹窗组件
1. 可重复使用的弹窗主体应拆分为独立组件
2. 通用弹窗不得硬编码具体业务文案与业务逻辑
3. 确认、取消、关闭等基础操作应统一暴露结果
4. 弹窗组件不得自行控制其他页面显示隐藏
5. 弹窗内容差异较小时，应优先配置内容而不是复制新弹窗
6. 结构和交互明显不同的弹窗不得为了复用强行合并为单一巨型组件

## 十、复用限制
1. 不允许为了“提高复用率”加入当前不存在的抽象层
2. 不允许通过大量开关参数让一个组件承担完全不同的结构
3. 当组件配置项持续增加并导致大量条件分支时，应拆分组件
4. 仅视觉相似但职责不同的组件，不要求强制复用
5. 通用组件修改后不得破坏已有调用场景
6. 项目内已有同类组件时，不得重复创建功能等价的新组件

## 十一、禁止耦合
1. 禁止组件硬编码外部节点绝对路径
2. 禁止组件通过 `get_parent()` 连续向上查找业务节点
3. 禁止组件直接访问页面私有变量完成业务逻辑
4. 禁止组件直接控制场景切换、存档、广告等全局系统
5. 禁止多个组件互相直接持有节点引用形成双向依赖
6. 禁止外部脚本依赖组件内部深层节点路径

## 十二、禁止结构
1. 禁止复制多份仅颜色或文本不同的同类组件
2. 禁止一个组件内部同时包含多个无关业务模块
3. 禁止使用大量布尔变量组合表达复杂组件状态
4. 禁止通过隐藏大量备用节点切换完全不同的组件结构
5. 禁止组件依赖所在页面的固定节点层级
6. 禁止为了复用而制造大量条件判断和配置开关
7. 禁止保留已经被新组件替代的旧组件副本
