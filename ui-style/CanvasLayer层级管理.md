# CanvasLayer层级管理

> 本文件为项目Layer分配的唯一记录
> 括号内的组件共用对应界面的Layer

## 层级划分

| CanvasLayer | 模块 | 包含界面与节点组件 |
| :---: | :--- | :--- |
| 1～999 | 主游戏层 | `1`：主游戏界面（含HUD与操作控件）<br>`2`：局内功能界面 |
| 1000～1999 | 主菜单层 | `1000`：主菜单<br>`1001`：加载界面 |
| 2000+ | 弹窗通知层 | `2000`：说明弹窗<br>`2001`：设置界面<br>`2002`：结算弹窗 |
| 9999 | 调试工具 | `9999`：GM调试界面（专用层） |
