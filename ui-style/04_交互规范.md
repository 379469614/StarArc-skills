# 04_交互规范

> 记录当前项目必须遵守的强限制性交互规则，优先保留可量化、可检查、可直接执行的底层约束

## 一、点击区域
1. 移动端所有可交互控件的有效点击区域不得小于 `64 × 64 px`
2. 以上尺寸以 `1280 × 720` 或 `720 × 1280` 设计分辨率为基准
3. 图标、文字等视觉元素允许小于 `64 × 64 px`，但实际可点击区域不得低于该尺寸
4. 重要操作按钮高度不得低于 `80 px`
5. 相邻独立点击区域之间不得小于 `12 px`
6. 关闭按钮、返回按钮、图标按钮同样遵守 `64 × 64 px` 最小点击区域限制
7. 不允许使用细线、小文字、狭窄边缘作为唯一点击区域

## 二、触摸操作
1. 核心操作不得依赖双击
2. 非明确设计需求，不使用长按替代普通点击
3. 拖拽起始区域不得小于 `64 × 64 px`
4. 拖拽过程中不得因轻微偏移立即取消操作
5. 不设计依赖高精度像素级点击或拖拽的核心交互

## 三、误触限制
1. 危险操作不得与高频操作按钮紧邻放置
2. 删除、清空、覆盖、退出进度等不可逆操作必须提供二次确认或撤销机制
3. 页面切换、购买、提交等操作触发后，在处理完成前不得重复触发
4. 屏幕边缘不得放置需要高频精准操作的小型按钮

## 四、输入互斥
1. 同一次触摸输入只能由一个主要交互对象消费
2. 模态弹窗打开时，下层界面不得继续响应输入
3. UI 与游戏场景触摸区域重叠时，优先由 UI 消费输入
4. 拖拽开始后，当前拖拽对象应保持输入所有权，直到结束或主动取消

## 五、按钮状态
1. 禁用按钮不得响应点击
2. 操作触发后进入等待状态时，对应按钮必须暂时禁止重复触发
3. 可点击与不可点击状态必须在视觉和交互行为上保持一致

## 七、维护规则
1. 修改最小点击区域、按钮高度、交互间距或输入优先级时，必须同步维护本文件
2. 新增影响全项目的强限制性交互规则时，必须写入本文件
3. 单个界面的临时交互特例，不写入本文件
