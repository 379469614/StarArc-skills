# 01_视觉规范

> 记录项目 UI 的统一视觉约束，重点维护全局 `Theme`、组件主题样式与视觉状态规则

## 一、全局 Theme
1. 项目必须使用统一的全局 `Theme` 作为基础视觉来源
2. 通用字体、默认字号、基础颜色与常用控件样式应优先配置在全局 `Theme`
3. 不允许同类控件在多个场景中分别重复维护相同基础样式
4. 新增或修改全局 `Theme` 内容时，必须同步检查并维护本规范
5. 局部界面不得无必要覆盖全局 `Theme`
6. 项目存在多个主题资源时，必须明确各自职责，不允许功能重叠

## 二、Theme Variation
1. 同类控件存在高亮、普通、警示等视觉差异时，优先使用 `Theme Type Variation`
2. 仅颜色、边框、字体颜色等视觉属性不同的控件，不得复制独立组件实现
3. 不允许为每个具体按钮单独创建一套完整 Theme
4. Variation 命名必须能直接表达用途，不使用无语义编号
5. 同一用途不得重复创建多个等价 Variation
6. 不允许通过大量局部 Override 替代已有 Variation

## 三、字体
1. 项目默认字体必须由全局 `Theme` 统一指定
2. 同一语言环境下不得在普通 UI 中混用多套正文字体
3. 特殊标题字体仅允许用于明确的装饰性或层级用途
4. 不允许在单个控件上直接指定字体资源来绕过全局字体规则
5. 字体替换时必须优先修改全局 `Theme`，不得逐场景修改
6. 字体资源必须保证项目目标语言字符完整覆盖

## 四、字号
1. 常用字号必须形成有限档位，不允许每个控件使用不同字号
2. 同一级信息应使用相同字号
3. 不允许仅通过随意放大字号制造视觉层级
4. 标题、正文、辅助文本、按钮文字应使用固定字号档位
5. 局部字号 Override 仅在明确特殊需求下使用
6. 新增字号档位前，应确认现有档位无法满足需求

## 五、颜色
1. 项目主题色必须保持有限数量
2. 主色、强调色、警示色等用途必须明确
3. 同一语义不得在不同界面使用不同颜色表达
4. 不允许在场景中大量直接填写临时颜色值
5. 通用颜色应优先通过 `Theme` 或统一样式资源维护
6. 相近但无明确语义区别的颜色不得重复增加
7. 禁用、警示、成功等状态颜色不得与普通状态混淆

## 六、StyleBox
1. 同类控件的背景、边框、圆角与内边距应通过统一 `StyleBox` 规则维护
2. 仅颜色不同但结构相同的样式，不得重复制作多套完全独立资源
3. 相同圆角、边框宽度与阴影规则不得在多个控件中重复手工配置
4. 不允许通过贴图模拟原本可由 `StyleBox` 完成的简单矩形 UI
5. `StyleBox` 的内边距必须与实际内容布局匹配
6. 同类控件不得出现无设计依据的圆角、描边或阴影差异

## 七、按钮视觉
1. 同类按钮必须共享统一基础形状、描边、圆角和文字规则
2. 高亮、普通、警示按钮之间优先只改变必要视觉属性
3. 按钮至少维护 `Normal / Pressed / Disabled` 对应视觉状态
4. Web 或 PC 平台存在鼠标操作时，再补充 `Hover` 状态
5. 不允许不同按钮各自使用完全不同的按下反馈规则
6. 禁用状态必须与正常状态具有明显视觉区别

## 八、文本视觉
1. 正文文本不得随意使用描边、阴影或渐变
2. 文本描边仅用于提高可读性或满足明确美术需求
3. 同一层级文本的字体、字号、颜色规则必须一致
4. 不允许通过大量不同颜色区分本可通过布局层级表达的信息
5. 重要文本与普通文本必须有明确且统一的视觉层级
6. 文本颜色必须保证与背景存在足够对比

## 九、图标视觉
1. 同类功能图标必须保持一致的线条粗细和视觉风格
2. 同一界面不得混用明显不同风格的图标资源
3. 图标颜色应优先跟随 Theme 或统一状态规则
4. 不允许通过随意缩放导致同类图标视觉重量明显不同
5. 图标按钮的视觉尺寸与实际点击区域必须分离处理
6. 同类图标不得同时存在多套含义相同但样式不同的资源

## 十、局部 Override
1. `Theme Override` 只允许处理明确的局部特殊需求
2. 可通过全局 `Theme` 或 Variation 解决的问题，不允许使用 Override
3. 同一 Override 在 `2` 个及以上场景重复出现时，应考虑提升至 Theme
4. 不允许通过大量 Override 形成隐性第二套视觉规范
5. 修改 Override 前必须确认不会破坏全局统一性
6. 页面级 Override 不得影响其职责范围外的组件

## 十一、资源复用
1. 相同视觉效果必须优先复用已有 Theme、Variation 或 StyleBox
2. 不允许因单个页面需求复制一份几乎相同的主题资源
3. 已存在等价样式时，不得新增重复资源
4. 视觉资源命名必须体现用途，不使用 `new_theme`、`style1` 等临时名称
5. 废弃 Theme 与 StyleBox 资源应删除，不长期保留备用副本
6. 修改共享视觉资源前必须确认其影响范围

## 十二、维护规则
1. 修改全局字体时，必须同步检查本规范
2. 修改全局字号档位时，必须同步检查本规范
3. 修改主题色、状态色时，必须同步检查本规范
4. 新增或修改 `Theme Type Variation` 时，必须同步检查本规范
5. 新增全局 StyleBox 规则时，必须同步检查本规范
6. 新增大量局部 Theme Override 时，必须检查是否应升级为全局规则

## 十三、禁止项
1. 禁止同类控件在不同场景分别维护基础视觉样式
2. 禁止为每个按钮创建独立 Theme
3. 禁止大量使用 Theme Override 替代全局 Theme
4. 禁止普通 UI 混用多套正文字体
5. 禁止无规则增加字号档位
6. 禁止无语义增加相近颜色
7. 禁止复制大量仅细节不同的 StyleBox
8. 禁止通过场景局部配置形成与全局 Theme 冲突的第二套视觉体系
