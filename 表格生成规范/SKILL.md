# 表格生成规范 —— AI 编写 xlsx 的规范

## 核心原则

1. **xlsx 是 zip+xml 压缩包，必须用库（openpyxl）生成**，禁止手写 XML、解压后直接改文件
2. **单元格值是"类型敏感"的**：数字、文本、日期、公式在底层是不同存储类型。AI 必须显式控制每个单元格的类型，不允许让 openpyxl 或 Excel 自动推断
3. **先确认"谁在读它"，写完必须实测验证**：写表前了解目标程序/导出工具的读取要求，写完后用 openpyxl 读回 + 用消费方工具实测，才算完成
4. **可读性也是交付的一部分**：表头清晰、列宽合理、必要时加粗表头（不影响数据，但让文件可直接给人看）

## 硬性约束（面向本工程的导表工具）

1. **表名 / sheet 名必须为中文**：可导出工作表名 = `|` + **纯中文标记名**（如 `|英雄`）。`|` 后只允许中文字符；`|Hero`、`|hero_1`、`|英雄2` 均不合法。带 `|` 标记的 sheet 即为可导出表
2. **标记名不可重复（同/跨 xlsx）**：标记名即导出文件名，因此**同一工作簿内多个 sheet 之间、不同工作簿之间**都不可重复。生成前盘点所有工作簿的全部 `|标记`，确保全局唯一；违反会导致导出文件互相冲突/覆盖
3. **数据表字段名必须为中文**：数据表第 1 行的字段名（A1 除外）写中文（如 `名字`、`生命`）。例外：**A1 必须为 `ID`、A2 必须为 `key`**——这是工具强制的英文识别词，改成中文会整表报错跳过；配置表首行的 `name`/`value`/`type`/`sign`/`description` 同样是工具英文识别词，不可改中文
4. **可导出字段名不可重复（同表内）**：数据表第 1 行中**可导出列**（第 2 行类型非空且非 `none`、第 1 行有名称）的字段名在同一表内不可重复；`none` 列与第 2 行未写类型的列不参与判断。重复时报错并整表跳过，格式：`文件.xlsx的sheet名内C1和E1存在相同字段名：“英雄”`

## 编写流程（AI 必须按序执行）

1. **确认需求与约束**：谁读这份 xlsx？表型（数据表=多行记录 / 配置表=键值参数）？字段与数据内容？目标工具的约束（见"与项目导出要求对接"）？不确定先向用户确认
2. **规划**：为每张表定**纯中文且全局唯一**的标记名；确定每张 sheet 的列结构（表头行数、**中文字段名**、字段类型、数据起始行）
3. **用 openpyxl 创建并写入**（遵循下方"写入规范"）
4. **保存**为 `.xlsx`
5. **验证**：openpyxl 读回检查单元格类型与值；再用目标消费方实测读取（本工程：`导表工具_AI.py`）
6. **交付**并说明表结构、导出结果

## openpyxl 写入规范

### 工作簿与工作表

- 创建：`wb = openpyxl.Workbook()`；首个工作表用 `wb.active`（改名复用），其余用 `wb.create_sheet("|标记")`；`ws.title = "|标记"` 可改名
- sheet 名是写表时最容易出错的地方：
- Excel 禁止字符：`\` `/` `?` `*` `[` `]` `:`，命名时避开
- 本工程约束：必须是 `|` + 纯中文标记名；且所有 sheet 的标记名全局唯一
- 同一个 xlsx 里若有无需导出的表，就不要加 `|` 前缀（不加 `|` 的表不会被导出）
- sheet 顺序按业务逻辑排：`wb.create_sheet(名称, 索引)` 可控制插入位置

### 单元格值类型控制（最关键的一节）

数字、文本、日期、公式是四种不同存储类型，AI 写每个单元格时都要明确它该是哪种：

| 想写入的语义 | 正确写法 | 读取方（sxl/openpyxl）得到 |
| --- | --- | --- |
| 整数/浮点 | `ws.cell(r, c, value=100)` / `value=1.5` | 数字（整数读到 `100.0` 属正常，按类型解释即可） |
| 文本 | `ws.cell(r, c, value="奥丁")` | `'奥丁'` |
| 文本（数字长相） | `value="00123"` 写字符串 | `'00123'`（前导零保留） |
| 文本（长数字） | `value="12345678901234567890"` 写字符串 | 文本完整保留，不会被科学计数法截断 |
| 文本（日期长相） | `value="2024-01-01"` 写字符串 | `'2024-01-01'`，不会被转成日期 |
| **文本（以 `=` 开头）** | `c = ws.cell(...); c.value = "=1+1"; c.data_type = "s"` | `'=1+1'`（文本） |
| 真假 | `value=True` / `value=False` | `True` / `False` |

**必须规避的自动推断坑：**

1. **以 `=` 开头的字符串会被 openpyxl 当公式**，读取方拿到公式缓存值（无缓存时是 `None`，等同空值）→ 内容静默丢失。强制文本：先赋 `value`，再 `cell.data_type = "s"`
2. **不要写"长得像数字"的字符串来"表示"文本**（如直接写 `"007"`、`"1E3"`、`"100.0"` 后又期望它仍是数字语义）——写 str 就是文本，写数字就是数字，二者由你显式决定，不靠 Excel 猜
3. 日期若需要"文本形式"用字符串写入；若需要真日期用 `datetime` 对象
4. 空单元格用 `None`；**空字符串 `""` 写入后读出也等同空单元格**（本工程按字段类型输出默认值），不要把 `""` 当成"有内容"

### 单元格内换行

- 文本内换行直接写 `"\n"`（读取方保留换行）；要让人在 Excel 里**看到**换行，需给该单元格开 `wrap_text` 样式
- 本工程 string 列另有转义约定（见"与项目导出要求对接"），两者不冲突

### 样式（可读性，不影响数据）

- 表头加粗：`from openpyxl.styles import Font; cell.font = Font(bold=True)`
- 列宽：`ws.column_dimensions['A'].width = 20`
- 冻结首行、加边框、底色等按需使用，只影响显示

### 保存规范

- 保存 `.xlsx`（**不要存成旧格式 `.xls`**）；`wb.save("路径/文件名.xlsx")` 前确保目录存在
- 覆盖旧文件前先确认；目标文件正被 Excel 打开时保存会失败，需先关闭
- 大表格（数万行）用 `wb = openpyxl.Workbook(write_only=True)` 的只写模式（此模式只能逐行写、不能回改单元格）
- 保存后自行用 openpyxl 读回一遍，确认能正常打开（也是验证的第一步）

## 生成后验证（强制步骤）

1. **openpyxl 读回**：`wb2 = openpyxl.load_workbook(路径)`，遍历每个工作表，抽查单元格值类型与预期一致——重点查：`=` 开头文本（应为字符串而非公式）、前导零/长数字（应为字符串）、空值（应为 `None`）
2. **用目标消费方实测**（本工程）：`python 导表工具_AI.py -p 文件.xlsx -f 输出目录 -e json --json`
   - 成功判定：`success: true`、`exported` 含全部预期导出文件、`errors: []`
   - 有错误时按报错（含文件名、sheet 名、列字母+行号）定位修正，重新导出
3. **确认 Excel 打开无警告**：单元格不要写入非法 XML 控制字符（`\x00`~`\x08` 等），否则 Excel 打开会提示文件损坏
4. 若消费方工具不在手边，先用现成表（本工程 `测试配置/` 下的 xlsx）跑通基线，再验证自己的表

## 常见错误清单

| 现象 | 原因与修正 |
| --- | --- |
| 以 `=` 开头的内容导出为空 | openpyxl 当公式写入，读取方拿到 `None`；用 `cell.data_type = "s"` 强制文本 |
| 长数字 / 大整数导出被截断或变科学计数法 | 写成了数字；按文本需求用字符串写入 |
| 前导 0 丢失 | 写成了数字；用字符串写入（`"007"`） |
| 保存后 Excel 提示文件损坏 | 手改了 XML 结构，或写入了非法控制字符（`\x00`~`\x08`） |
| 单元格内换行在 Excel 里不显示 | 文本里有 `\n` 但单元格未开 `wrap_text` |
| 空值没有"按预期"输出 | 空单元格/空字符串导出时按字段类型给默认值（0 / 0.0 / false / ""），这是读取方行为，不是漏写 |
| sheet 名含 `\ / ? * [ ] :` | Excel 非法命名，改名后再保存 |
| 表没被导出 | 本工程：sheet 名没带 `|` 前缀；或标记名重复/非纯中文 |
| 标记名重复导出冲突 | 同/跨工作簿出现相同 `|标记`；生成前全局盘点去重 |
| 标记名含英文/数字 | 违反纯中文约束（`|Hero`、`|英雄2` 不合法） |
| 报错“存在相同字段名” | 同表内可导出列字段名重复；第 1 行改名保证唯一（`none`/未写类型列不参与判断） |

## 与项目导出要求对接（约束落实，本工程导表工具）

AI 生成 xlsx 前，必须先把本工程的导出要求"翻译"成具体的单元格写法：

| 导出要求 | 落实到 xlsx 的写法 |
| --- | --- |
| 表名标记 | sheet 名 = `|` + **纯中文标记名**；标记名全局唯一；导出文件名=标记名 |
| 表型判定 | 数据表：第 1 行字段名、第 2 行字段类型、第 3 行起数据；配置表：首行含 `name`/`value`/`type` |
| 数据表强校验 | A1 必须是 `ID`、A2 必须是 `key`（精确英文词），否则整表报错跳过 |
| 字段名语言 | 数据表第 1 行字段名（A1 除外）用中文；`ID`/`key` 与配置表首行 `name`/`value`/`type` 为工具英文识别词，不可改中文 |
| 字段名唯一 | 同表内可导出列（第 2 行类型非空且非 `none`）字段名不可重复；重复报错 `文件.xlsx的sheet名内C1和E1存在相同字段名：“英雄”`，整表跳过；`none`/空类型列不参与判断 |
| 字段类型 | 第 2 行类型**必须小写**：`int`/`long`/`float`/`string`/`bool`/`T[]`/`{类型 字段;...}`/`int(表.字段)`/`none`；类型列为 `none` 的列整列不导出 |
| ID/key | 写数字或数字字符串均可，导出时 key 归一并转字符串（`1` → `"1"`） |
| 数组列 `T[]` | 单元格写**半角逗号**分隔的文本：`"1,2,3"` |
| 对象列 `{int Min;int Max}` | 单元格写**分号**分隔的文本：`"1;99"`（字段顺序对应声明顺序） |
| 注释行 | 数据表 A 列写 `#` 开头 |
| 签名行 | 数据表 A 列写 `!签名!key`；命中 `-s` 签名或未指定 `-s` 时该行被跳过 |
| 空值 | 单元格留空，导出时按字段类型输出默认值（0 / 0.0 / false / ""） |
| 字符串转义 | string 列文本内：`\n` 表示换行、`\,` 表示逗号、`\;` 表示对象分隔符 |

### 端到端示例（可直接运行验证）

用 openpyxl 生成 `|英雄`（数据表）+ `|全局参数`（配置表），再用导出工具实测：

```python
#!/usr/bin/env python3
"""示例：生成 生成示例.xlsx（数据表 |英雄 + 配置表 |全局参数）。"""
import openpyxl

wb = openpyxl.Workbook()

# ---- 数据表 |英雄（纯中文标记名）----
ws = wb.active
ws.title = "|英雄"
ws.append(["ID", "名字", "生命", "武器", "属性", "坐骑", "启用"])
ws.append(["key", "string", "int", "string[]", "{int Min;int Max}", "int(Mount.Id)", "bool"])
ws.append([1, "奥丁", 1000, "神枪,雷锤", "1;99", 10001, True])
ws.append([2, "洛基", 800, "诡计", "1;50", 10003, False])
ws.append(["# 注释行不导出", None, None, None, None, None, None])

# ---- 配置表 |全局参数 ----
ws2 = wb.create_sheet("|全局参数")
ws2.append(["name", "value", "type", "sign", "description"])
ws2.append(["NameLimit", 7, "int", "", "名字字数限制"])
ws2.append(["LevelRange", "1;99", "{int Min;int Max}", "", "等级区间"])

wb.save("生成示例.xlsx")
print("已生成 生成示例.xlsx")
```

```bash
python 导表工具_AI.py -p 生成示例.xlsx -f /tmp/示例输出 -e json --json
# 成功时 exported 含 英雄.json、全局参数.json，errors 为空
```

## 快速参考表

| 要做的 | 写法/规则 |
| --- | --- |
| 建簿 | `wb = openpyxl.Workbook()` |
| 建表/改名 | `ws = wb.create_sheet("|英雄")` / `ws.title = "|英雄"` |
| 写值 | `ws.cell(行, 列, value=值)` 或 `ws.append([...])` |
| 数字 | `value=100` / `value=1.5`（读回为 `100.0` / `1.5` 正常） |
| 文本 | `value="字符串"`（数字长相、长数字、日期串写 str 即保持文本） |
| `=` 开头文本 | `c = ws.cell(...); c.value = "=…"; c.data_type = "s"` |
| 空值 | `None`（空字符串读出也等同空值） |
| 换行 | 文本内 `"\n"`；显示需 `wrap_text` |
| 表头加粗 | `from openpyxl.styles import Font; c.font = Font(bold=True)` |
| 保存 | `wb.save("xx.xlsx")`（.xlsx，目录先建好） |
| 本工程表名 | `\|` + 纯中文标记名，全局唯一 |
| 本工程数据表 | 第 1 行字段名用中文（A1=`ID` 例外）、第 2 行类型（小写）、第 3 行起数据；A2=`key` |
| 本工程配置表 | 首行 `name`/`value`/`type`（可加 `sign`/`description`） |
| 验证 | `python 导表工具_AI.py -p 文件.xlsx -f 输出 -e json --json` |
