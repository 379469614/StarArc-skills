# 工作树提交规范

1. 提交前检查当前 Worktree、Git 状态及变更范围
2. 仅提交当前任务的修改，不包含无关文件
3. 提交信息需要从功能向说明清楚当前的修改内容，而不是改了什么文件之类的无用信息
4. detached HEAD 下需要长期保存或合并成果时，创建任务分支
5. 允许自主完成当前任务的普通 Git 提交
6. 合并 main 前必须检查目标分支状态，并获得用户确认
7. main 存在未提交修改或其他合并任务时，暂停并报告
8. 遇到无法安全解决的合并冲突时，停止并报告
9. 禁止擅自丢弃、覆盖其他 Worktree 或 main 的修改
10. 禁止未经授权执行破坏性 Git 操作
11. 合并完成后执行必要的自动化测试，并报告结果
12. 默认保留任务 Worktree 和分支，清理需用户确认
13. 当用户说“合并任务”的时候是指将当前会话工作树修改的内容提交并创建分支合并到main
