# 模板：表现风格

用途：`1项目文档/0-设计/表现风格.md`，美术与音频的整体基调，用于判断新素材是否"跑偏"。

```markdown
# 表现风格

> 最后更新：YYYY-MM-DD | 状态：草案 / 生效

## 美术基调

- 整体风格：（如像素 / 低多边形 / 手绘）
- 色彩倾向：主色、辅色、禁用色
- 镜头与视角：
- 参考作品与参考点：

## 反馈基调

玩家操作后应获得什么强度的反馈，整体手感偏"轻快"还是"厚重"。

| 事件 | 反馈层次 | 强度 |
|---|---|---|
| 普通命中 | 画面 + 音效 | 弱 |
| 暴击 | 画面 + 音效 + 震屏 | 强 |

## 音频基调

- 音乐风格与情绪走向
- 音效密度与音量层级
- 静音场景下如何保证信息不丢失

## 一致性约束

- 新素材必须满足什么条件才能加入
- 明确排除的表现手法

## 未决问题

- [ ] <待定项，附日期>
```

## 维护要点

- 具体到每个素材的规格（尺寸、格式、命名）属于 `3-内容规范/`，本篇只定基调。
- 「一致性约束」是判断新素材能否采用的硬标准，写得越具体越好。
- 风格调整属 L3——会影响已完成的全部素材，必须先向用户确认。
