# 模板：叙事与世界观

用途：`1项目文档/0-设计/叙事与世界观.md`。**无叙事需求的游戏（如纯机制类）可整篇省略**，索引中标注"不适用"即可。

```markdown
# 叙事与世界观

> 最后更新：YYYY-MM-DD | 状态：草案 / 生效 / 不适用

## 世界观核心

（用两三句话说清这个世界是什么样的、与现实的差异点是什么。）

## 叙事基调

严肃 / 轻松 / 荒诞 / 留白……整体讲述方式是什么。

## 叙事载体

| 载体 | 使用场景 | 篇幅约束 |
|---|---|---|
| 过场对话 | 关卡节点 | 单段不超过 3 句 |
| 环境叙事 | 场景细节 | 不强制玩家阅读 |
| 物品描述 | 道具详情 | 单条 1-2 句 |

## 角色设定原则

- 角色在功能上承担什么作用（引导者 / 对手 / 陪伴者）
- 性格设定的边界，避免与玩法体验冲突

## 叙事与玩法的关系

- 叙事是否可跳过
- 剧情推进是否依赖玩法进度（反过来是否成立）
- 玩家跳过全部叙事后，玩法是否仍完整

## 一致性约束

- 设定中不可触碰的红线
- 与已发布内容冲突时的处理原则

## 未决问题

- [ ] <待定项，附日期>
```

## 维护要点

- 无叙事需求的游戏不要硬填，直接标注"不适用"，空模板比假内容强。
- 「叙事与玩法的关系」决定实现复杂度，改动这块属 L3。
- 具体台词、剧情文本不放本文档，放内容表，此处只记原则。
