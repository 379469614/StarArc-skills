# 模板：进度与存档

用途：`1项目文档/1-架构/进度与存档.md`，记录存什么、何时存、如何兼容旧档。

```markdown
# 进度与存档

> 最后更新：YYYY-MM-DD | 状态：生效

## 存档内容

- 当前进度：已通关关卡、当前所在位置
- 角色状态：等级、属性、持有道具
- 设置项：音量、操作偏好

## 存档时机

- 自动：关卡结束时、关键剧情节点后
- 手动：玩家在菜单中主动保存

## 版本兼容原则

- 每次修改存档结构必须递增版本标识
- 必须保留旧档读取与转换路径，禁止直接废弃
- 转换失败时的兜底：保留原始档案，提示玩家而非静默清空

## 变更历史

| 版本 | 变更内容 | 旧档处理 |
|---|---|---|
| 1 → 2 | 新增背包数据 | 旧档补充空背包 |
| 2 → 3 | 生命值拆分为当前值 / 上限 | 上限取默认值 |

## 未决问题

- [ ] <待定项，附日期>
```

## 维护要点

- **硬规则**：存档结构变更但未提供旧档转换路径 → 直接判定为 L3 冲突，必须向用户提出。
- 「变更历史」表要一直累加，不删旧行——它是版本迁移逻辑的唯一依据。
- 具体字段名、类型不写，只写"存什么类别的内容"和"兼容原则"。
