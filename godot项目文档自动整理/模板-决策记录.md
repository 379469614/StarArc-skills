# 模板：决策记录（ADR）

用途：`1项目文档/4-决策记录/ADR-0001-<标题>.md`，记录重大设计决策的来龙去脉。

```markdown
# ADR-0001：<决策标题>

- 日期：YYYY-MM-DD
- 状态：已接受 / 已废弃 / 被取代（被 ADR-00XX 取代）

## 背景

要解决什么问题、当时面临什么约束。

## 决策

选了什么方案。（用设计语言描述，不写实现细节）

## 理由

为什么选它、代价是什么。

## 备选方案

| 方案 | 否决原因 |
|---|---|
| | |

## 影响

哪些系统、哪些文档因此改变。
```

## 使用规则

- **只在 L3 级别改动时创建**：核心玩法变更、流程改造、全局服务增删、职责边界重划、存档策略变更。
- 编号从 0001 起递增，**永不复用、永不删除**。被取代的 ADR 保留原文，状态改为"被取代"并指向新 ADR。
- 决策用设计语言写，不写实现细节——ADR 保存的是"为什么"，不是"怎么搭"。
- `4-决策记录/README.md` 维护一份 ADR 列表，含编号、标题、日期、状态。
