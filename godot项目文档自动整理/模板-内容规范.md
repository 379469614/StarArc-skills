# 模板：内容规范

用途：`1项目文档/3-内容规范/`，记录内容的分类维度与组织约定。

```markdown
# 内容规范

> 最后更新：YYYY-MM-DD | 状态：生效

## 内容分类维度

| 内容类型 | 分类依据 | 扩展方式 |
|---|---|---|
| 关卡 | 按难度分区，每区 N 关 | 新增分区即可扩展 |
| 角色 | 按定位（输出 / 防御 / 辅助） | 新增定位需同步数值框架 |
| 道具 | 按用途（消耗 / 装备 / 材料） | 新增用途属 L3 |

## 命名约定

- 内容标识命名规则（如 `关卡_区域_序号`）
- 命名中必须包含什么、禁止包含什么

## 素材规格

- 通用规格：尺寸、格式、色彩空间
- 各类素材的特殊约束

## 新增内容的检查清单

- [ ] 分类维度是否需要扩展
- [ ] 命名是否符合约定
- [ ] 素材是否满足规格与 [表现风格](../0-设计/表现风格.md)
- [ ] 是否需要在 [数值框架](../0-设计/数值框架.md) 补充对应条目

## 未决问题

- [ ] <待定项，附日期>
```

## 维护要点

- 分类维度变化属 L3——会牵动所有既有内容的组织方式，必须先确认。
- 素材规格只写通用约束，逐条素材清单放内容表。
- 「新增内容的检查清单」是给 AI 用的，改动内容结构时逐条过一遍。
