# 音效格式要求

适用于音效、音乐、环境音和语音

## 工程外母版与备份

- 将音频源文件放在项目的 `3音效资源备份/`
- 保留原始格式和原始质量等完整的原始信息，不做任何修改
- 禁止覆盖母版
- 仅将需要使用的音频导出到工程内

## 工程内格式

- 工程内音频仅允许 `.wav`、`.ogg`
- 可以使用ffmpeg工具来处理音频格式
- WAV 用于短音效、高频音效
- WAV 可启用 Godot 的 QOA 导入压缩
- OGG 用于背景音乐、环境音和长音效
- OGG 使用质量2进行压缩

## 响度标准化

1. 音频进入工程前，按用途分类并进行响度标准化
2. 区分核心反馈、普通反馈、辅助反馈、持续背景声和音乐
3. 不同类别使用独立的目标响度
4. 短音效参考 RMS 和峰值，长音效及音乐参考 LUFS
5. 使用 FFmpeg 自动处理，优先采用静态增益
6. 保留动态范围，避免削波和过度压缩
7. 处理后检查响度与峰值，异常文件需人工确认
8. Godot 不重复标准化，最终音量由播放音量和音频总线控制

## 替换与删除

- 遵循主文件的资源管理规范
- 删除工程内音频前，先备份原文件
- 将备份放在 `3音效资源备份/`
- 保留原文件格式和质量
- 备份不得覆盖母版
- 确认备份完整后，再删除工程内音频
- 不需要备份.import后缀的文件
