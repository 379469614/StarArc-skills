# 图片格式要求

## 工程外母版与备份

- 将图片源文件放在项目的 `2美术资源备份/`
- 保留原始格式、原始分辨率和原始质量等完整的原始信息，不做任何修改
- 禁止覆盖母版
- 仅将需要使用的图片导出到工程内

## 工程内格式

- 工程内图片仅允许 `.webp`、`.svg`
- 可以使用ffmpeg工具来处理图片格式
- 普通图片使用默认质量90的有损 WebP 压缩，已经有损压缩的不要重复压缩
- UI、像素画使用无损 WebP 压缩
- 图片的分辨率大小要结合当前项目分辨率和实际最大实际显示尺寸调整，考虑缩放需求，避免过度缩小
- SVG 用于简单矢量图
- 复杂 SVG 需检查 Godot 渲染兼容性

## 替换与删除

- 遵循主文件的资源管理规范
- 删除工程内图片前，先备份原文件
- 将备份放在 `2美术资源备份/`
- 保留原文件格式、分辨率和质量
- 备份不得覆盖母版
- 确认备份完整后，再删除工程内图片
- 不需要备份.import后缀的文件
