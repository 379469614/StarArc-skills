# 图片格式要求

## 工程外母版与备份

- 将图片源文件放在项目的 `2美术资源备份/`
- 源文件包括 PSD 等原始素材
- 保留原始格式、原始分辨率和原始质量
- 禁止覆盖母版
- 仅将需要使用的图片导出到工程内

## 工程内格式

- 工程内图片仅允许 `.webp`、`.svg`
- 普通图片使用有损 WebP 压缩
- UI、像素画使用无损 WebP 压缩
- SVG 用于简单矢量图
- 复杂 SVG 需检查 Godot 渲染兼容性

## 替换与删除

- 遵循主文件的资源管理规范
- 删除工程内图片前，先备份原文件
- 将备份放在 `2美术资源备份/`
- 保留原文件格式、分辨率和质量
- 备份不得覆盖母版
- 确认备份完整后，再删除工程内图片
